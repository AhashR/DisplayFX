# DisplayFX 2.2.4

- A connected monitor remains selected until you switch. Identify displays uses active Windows display paths rather than GDI device-name suffixes.
- Pick from ten preset profile icons via the profile context menu. Custom marker colors are no longer displayed.
- Workspace is removed. Profile actions are on the profile context menu, with profile files, profile sets and updates in the main toolbar menu.
- The linked application picker starts in the current executable’s folder. The per-profile shortcut recorder is removed. Previously saved shortcuts can be removed via the profile context menu.
