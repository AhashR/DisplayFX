# DisplayFX 2.2.3

Workspace now contains Profiles, Profile files, and Updates. The profile file screen imports or exports one JSON profile at a time, via user-selected locations. No automatic backups, snapshots, full-settings imports, scheduled brightness changes, or user-facing diagnostic tools remain.

The app keeps one working settings file in the installation folder's Settings directory when writable, otherwise in Documents. It reads earlier AppData settings once when migrating and does not change or delete the old files. The four slider values are editable in place. Linking an app to a profile and profile or brightness shortcuts still work.
