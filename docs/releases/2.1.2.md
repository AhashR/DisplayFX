DisplayFX 2.1.2 addresses the software review with safer brightness handling, asynchronous profile application, recovery improvements, and new import and diagnostic tools.

- Profiles change GPU color settings only. Automatic physical-backlight corrections have been removed. Profile application and brightness-popup initialization run outside the UI thread.
- Fixed stale slider completions, stale refresh results, and shortcut/slider read-modify-write races. Sleep is rechecked inside monitor operations; delayed schedule retries cannot replace newer explicit brightness changes.
- Active color profiles are reapplied after display invalidation, and restoring settings reconciles the resulting active profiles. Automatic failures use nonmodal feedback with a 30-second retry interval. Combined color updates require a usable rollback snapshot.
- Failed daily schedules retry failed or missing outputs, with bounded attempts. Invalid numeric schedule drafts survive pagination and prevent saving.
- Added strict startup-settings validation and executable-link conflict detection. Ambiguous physical outputs are disabled for independent brightness control rather than risking writes to the wrong panel.
- Added rotating per-user logs and opt-in, read-only color-change diagnostics, including delayed brightness observations. Drivers, monitor dynamic contrast/HDR settings, and other brightness software may still change physical brightness independently; the original intermittent hardware reset was not reproduced by the automated tests.
- Added serial-based monitor matching across ports/docks with ambiguity safeguards, single-profile color import, and unsaved-draft warnings before settings restore.
- Improved Settings access on small/high-DPI screens, popup placement on the clicked taskbar's monitor, and the distinction between color brightness and physical backlight brightness. Removed routine forced garbage collections and added startup-entry uninstall cleanup.
- Added Windows CI and deterministic regression coverage. The release candidate passes 553 hardware-independent checks and builds without warnings.
