# DisplayFX 2.2.0-preview.1

Large feature preview: appearance and localization, precise color editing, extended profiles, safe previews, Workspace, richer automation, monitor capabilities, backups, local CLI and release preparation.

- Light/dark/system appearance, accent, density and 100–200% text scale; English/Dutch interface resources.
- Up to 100 profiles per monitor, search, favorites, ordering, metadata, notes and modification dates.
- Numeric color input, individual resets, extended color undo/redo, RGB gains and approximate temperature tint.
- Timed previews, keep/cancel, hold-to-compare and restoration of original session colors.
- Multiple application links, priority/fullscreen/power rules, focus delay and temporary pauses.
- Weekly/per-monitor/solar brightness schedules, groups, offsets, bounds, shortcut targets and transitions.
- Read-only hardware scans, advertised VCP controls, compatible internal-panel WMI brightness and advanced-color gamma protection.
- Status history, redacted report preview/export, targeted reconnect and observation of external gamma changes.
- Selective backup import, merge preview, bounded snapshots, protected pre-upgrade backup and explicit portable/per-user storage preparation.
- Same-user/session named-pipe CLI (`DisplayFX.Cli list`, `DisplayFX.Cli apply <profile-id>`), requested update checks and Stable/Test channels.
- Certificate-store signing preparation, checksums and a manual hardware-evidence gate for stable publication.

This is an unsigned local preview until a real publisher certificate is supplied. Native ADLX/IGCL saturation backends are not provided; only NVIDIA hardware is available for verification. A successful API response and a passed fake-display suite do not prove visual correctness on every GPU/monitor.

Exports now use format version 2 and can read version-1 backups. Before first upgrading existing settings, the app preserves `History/upgrade-before-format-2.json`; rotating snapshots do not remove it. To return to 2.1.x, close DisplayFX, preserve the preview's current `Data.json`, restore the protected pre-upgrade file as `Data.json`, then launch the older version. Older builds do not understand every new profile option or the higher profile limit.

No remote release is published by building this preview locally. See the feature implementation matrix and hardware qualification document for detailed availability and verification limits.
