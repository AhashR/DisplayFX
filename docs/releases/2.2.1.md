# DisplayFX 2.2.1

Simplifies the desktop app by removing 28 options. See the implementation matrix for each original item.

- Removed customizable accent and density, language switching, favorite-based ordering, search, the custom editor shortcuts and extended screen-reader metadata, and the reduced-motion option. Built-in Windows keyboard navigation, themes, text scaling, normal profile/brightness shortcuts and profile favorite metadata are retained.
- Removed timed color previews, hold-to-compare, editable preset templates and software RGB/temperature controls. Standard color editing, undo/redo buttons, original session color restoration, and hardware RGB controls on supported monitors remain.
- Keeps one executable link per profile and everyday all-monitor brightness schedules. Removes app-rule pause, extra paths, priorities, focus delay, fullscreen/power filters and wake/dock reapply preferences. Old weekly, targeted or solar rules are ignored instead of being applied more broadly.
- Removes linked brightness offsets, configured limits, shortcut targeting and shortcut notifications. Brightness groups remain.
- Removes the test update channel and special pre-format-upgrade snapshots. Ordinary backups, update checks, legacy import and the signing/hardware qualification requirements for publishing remain.

Building locally does not publish a GitHub release.
